# Контракт модели трекера задач

## Границы и происхождение

Это новая учебная библиотека C# без графического интерфейса и без хранения данных на диске. Она моделирует действия из раздела 2 файла `lab-7/original/Specification.md`, но не является исходным кодом `todo_app.exe`. Поведение Windows-приложения по ней не проверялось. README исходного проекта упоминает `todo_app.py`, но в предоставленном репозитории исходного кода нет. Модель — отдельный объект тестирования.

## Общее состояние и результаты

У нового `TaskTracker` пустой упорядоченный список. Каждая запись `TaskEntry` имеет неизменяемые свойства `Text`, `IsCompleted`, `DisplayText`. Строка отображения формируется точно как `[ ] ` + текст или `[✓] ` + текст. Методы действий возвращают `OperationResult`: `Code`, `Message` и `ShouldClearInput`. При успехе `Message == null`. На результатах завершения и удаления `ShouldClearInput == false`. При ошибке списка и пустого текста поле списка не меняется.

| Публичный метод | Предусловия и постусловия | Исключения/допущения модели |
|---|---|---|
| `AddTask(string? text)` | Непустую строку добавляет в конец со статусом «не выполнена», прежние записи и статусы неизменны. `Success`, `ShouldClearInput = true` (сигнал интерфейсу очистить поле). | `null` или `string.IsNullOrWhiteSpace(text)` → `EmptyText`, сообщение `Текст задачи не может быть пустым!`, признак очистки false, список не меняется. Текст хранится как передан, без обрезки пробелов; дубли допускаются. |
| `CompleteTask(int? selectedIndex)` | Действительный индекс незавершённой задачи (нумерация с нуля): меняется только статус указанной задачи; число и порядок не меняются. `Success`. | `null` → `NoSelection`, сообщение `Выберите задачу из списка!`. Повтор → `AlreadyCompleted`, сообщение `Эта задача уже выполнена`. Нецелевого изменения списка нет. Любой переданный индекс вне `[0, Count - 1]` → `ArgumentOutOfRangeException` с `ParamName == "selectedIndex"`, до изменения списка. |
| `DeleteTask(int? selectedIndex)` | Действительный нулевой индекс: выбранная запись удаляется, остальные сохраняют текст, статус и относительный порядок. `Success`. | `null` → `NoSelection`, сообщение `Выберите задачу для удаления!`. Индекс вне `[0, Count - 1]` → `ArgumentOutOfRangeException` с `ParamName == "selectedIndex"`, до изменения списка. |
| `GetTasks()` | Возвращает доступный только для чтения снимок текущего списка неизменяемых записей. Позднейшие изменения трекера не меняют ранее полученный снимок. | Каждый экземпляр трекера независим; метод не меняет состояние. |

Вход `null`, индексы и исключения — соглашения API модели: в документе EXE описано только отсутствие выделения в GUI, поэтому оно представлено значением `null`; отрицательные/не существующие индексы являются ошибкой программного вызова, а не пользовательским предупреждением. В оригинальной спецификации не определены `null`, символы пробела кроме обычного, обрезка текста и поведение при повторяющихся текстах: модель расширяет правило пустоты до `IsNullOrWhiteSpace`, сохраняет исходный текст и допускает дубли. Это не утверждение о фактическом поведении EXE. Очистка поля представлена признаком в результате, реальное поле/диалог в модели не создаются и не проверяются. Никакие гарантии потокобезопасности и постоянного хранения не заявляются.
