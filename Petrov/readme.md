\# Командный трекер задач (To-Do List)

\*\*Авторы:\*\* Петров И.



\## Описание

Простое десктопное приложение для управления списком повседневных задач.



\## Инструкция по запуску

\* \*\*Вариант 1 (через исполняемый файл):\*\* Запустите файл `todo\_app.exe` двойным кликом мыши (требуется ОС Windows).

\* \*\*Вариант 2 (через исходный код):\*\* Убедитесь, что у вас установлен Python 3.x. Откройте терминал в папке с проектом и выполните команду:

&#x20; `python todo\_app.py`
