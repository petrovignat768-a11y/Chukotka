\# Функциональная спецификация: «Командный трекер задач v1.0»



\## 1. Общее описание интерфейса

Приложение состоит из одного главного окна размером 400x450 пикселей и модальных диалоговых окон уведомлений.

Элементы главного окна:

1\. Текстовое поле ввода задачи.

2\. Кнопка «Добавить задачу».

3\. Область отображения списка задач (`Listbox`).

4\. Кнопка «Отметить выполненной».

5\. Кнопка «Удалить задачу».



\---



\## 2. Описание действий (функций)



\### Действие 1: Добавление новой задачи

\* \*\*Предусловие:\*\* Приложение запущено, главное окно активно. В текстовое поле введена непустая строка символов.

\* \*\*Действие пользователя:\*\* Нажатие кнопки «Добавить задачу».

\* \*\*Постусловие:\*\* В конец списка задач добавляется новая запись с префиксом `\[ ] `. Текстовое поле ввода автоматически очищается.

\* \*\*Альтернативный сценарий:\*\* Если поле пустое или состоит только из пробелов, выводится модальное окно с предупреждением «Текст задачи не может быть пустым!», список не изменяется.

\* \*\*Инвариант:\*\* Существующие ранее в списке задачи и их статусы остаются неизменными.



\### Действие 2: Отметка задачи как выполненной

\* \*\*Предусловие:\*\* В списке есть хотя бы одна задача, и пользователь выделил ее курсором мыши. Статус задачи — не выполнена (`\[ ]`).

\* \*\*Действие пользователя:\*\* Нажатие кнопки «Отметить выполненной».

\* \*\*Постусловие:\*\* Префикс выбранной задачи меняется с `\[ ]` на `\[✓]`.

\* \*\*Альтернативный сценарий 1:\*\* Если задача не выделена, выводится предупреждение «Выберите задачу из списка!».

\* \*\*Альтернативный сценарий 2:\*\* Если задача уже имеет статус `\[✓]`, выводится сообщение «Эта задача уже выполнена».

\* \*\*Инвариант:\*\* Общее количество задач в списке и порядок их расположения не меняются.



\### Действие 3: Удаление задачи

\* \*\*Предусловие:\*\* В списке есть хотя бы одна задача, и пользователь выделил ее курсором мыши.

\* \*\*Действие пользователя:\*\* Нажатие кнопки «Удалить задачу».

\* \*\*Постусловие:\*\* Выбранная задача полностью удаляется из списка. Количество элементов в списке уменьшается на 1.

\* \*\*Альтернативный сценарий:\*\* Если ни одна задача не выбрана, появляется предупреждение «Выберите задачу для удаления!».

\* \*\*Инвариант:\*\* Все остальные (невыделенные) задачи сохраняют свой текст, статус и относительный порядок.
