## Использование

1. Распакуйте архив. `reports/ЛР2_отчёт.docx` … `reports/ЛР8_отчёт.docx` можно открыть и при необходимости отредактировать в Word или LibreOffice; личные данные и сведения об учебном заведении не выдумывались.
2. В каждой папке читайте `REPORT.md` и `README.md`, если он имеется. Большинство команд `cd lab-N` в отчётах рассчитано на терминал, открытый в корне распакованного комплекта. Журналы сохраняют исходные пути и дату машины, на которой были выполнены тесты: это записи фактических запусков, а не команды для копирования.
3. Для ЛР 2 нужны JDK 17+ и Maven, для ЛР 3 — .NET SDK 8, для ЛР 4 — CMake, компилятор C++17 и Google Test, для ЛР 5–6 — Python 3, для ЛР 8 — Python 3, Chromium и совместимый ChromeDriver. Установку сторонних зависимостей выполняйте по инструкции соответствующего отчёта. Тесты ЛР 8 запускают локальный сервер и не предназначены для публичного размещения.
4. Истории Git ЛР 5 и 6 включены как `lab-5/tdd-history.bundle` и `lab-6/lab-6-history.bundle`. Для просмотра диффов восстановите их командой `git clone` по инструкциям в отчётах. Авторы сохранённых коммитов — Manus, а не пользователь. Каталоги `.git` в архив не включены, чтобы папки можно было перенести в другой репозиторий.
5. В комплект намеренно не включены каталоги виртуальных окружений и кэши загрузки пакетов. Они создаются при повторной установке зависимостей. Если скрипт меняет локальные файлы или базу, запускайте его в отдельной тестовой копии, как описано в соответствующем отчёте.

**GitHub:** результаты не опубликованы, исходный репозиторий не изменялся. Для публикации нужен доступ на запись и выбор места размещения. Наличие адреса GitHub само по себе не предоставляет такой доступ.
