# Лабораторные работы 1–8: Методы тестирования и верификации программного обеспечения

Репозиторий содержит материалы, исходный код, наборы тестов, журналы выполнения и отчёты по лабораторным работам, выполненным в рамках дисциплины «Основы тестирования и верификации программного обеспечения» (по учебному пособию С. М. Старолетова).

## Структура репозитория

* `Petrov/` — материалы и файлы первой лабораторной работы (работа с системой контроля версий Git и GitHub).
* `lab-2/` — модульное тестирование на Java (JUnit).
* `lab-3/` — модульное тестирование на C# / .NET (MSTest).
* `lab-4/` — мультиплатформенное модульное тестирование на C++ (Google Test).
* `lab-5/` — разработка через тестирование (TDD, 5 циклов *red–green–refactor*).
* `lab-6/` — разработка, управляемая поведением (BDD, сценарии Gherkin / `behave`).
* `lab-7/` — функциональное тестирование настольного приложения (IBM Rational Functional Tester).
* `lab-8/` — автоматизированное тестирование веб-приложений (Selenium WebDriver и Selenium IDE).
* `reports/` — отчёты по лабораторным работам в форматах `.docx` и `.md`.

## Инструкция по запуску тестов

Для локальной проверки решений перейдите в каталог соответствующей лабораторной работы (`cd lab-N`) и воспользуйтесь инструкциями в локальных файлах `README.md` и `REPORT.md`.

### Системные требования
* **ЛР 2:** JDK 17 или выше, Apache Maven.
* **ЛР 3:** .NET SDK 8.0.
* **ЛР 4:** Компилятор с поддержкой стандарта C++17, CMake, библиотека Google Test.
* **ЛР 5, 6:** Python 3.10+, фреймворк `behave` (для ЛР 6).
* **ЛР 7:** ОС Windows, среда IBM Rational Functional Tester (руководство по запуску и настройке хранилища находится в `lab-7/RFT_GUIDE.md` и `lab-7/STORAGE.md`).
* **ЛР 8:** Python 3.10+, браузер Chromium и совместимый `ChromeDriver`.

### Примечания по структуре архива
* В целях соблюдения чистоты репозитория временные каталоги сборки, виртуальные окружения Python (`venv`) и кэши пакетов исключены и создаются при установке зависимостей.
* История коммитов для ЛР 5 и ЛР 6 сохранена в виде Git-бандлов (`lab-5/tdd-history.bundle` и `lab-6/lab-6-history.bundle`) и может быть развёрнута стандартной командой `git clone`.
