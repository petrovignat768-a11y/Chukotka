# Модель командного трекера задач — лабораторная работа 2

Это **самостоятельная Java-модель по текстовой спецификации**, а не исходный код приложения и не тестирование `todo_app.exe`. UI и исполняемого `main` в проекте нет: это библиотека, которую может вызывать интерфейс. Все данные хранятся только в памяти одного экземпляра; сохранение и восстановление не реализованы. Исходный репозиторий пользователя не изменён.

## Требования и команды

Необходимы JDK 17 или новее и Maven 3.8+; при первом запуске требуется доступ к Maven Central для загрузки зависимостей. Из папки проекта:

```bash
mvn -B -ntp -Dmaven.repo.local="$PWD/.m2/repository" clean test
```

Параметр помещает локальный репозиторий Maven внутрь папки лабораторной. `clean` удаляет предыдущие результаты, чтобы не накапливать данные покрытия разных прогонов. Результаты JUnit/Surefire находятся в `target/surefire-reports/`; сохранённый журнал выполненного запуска — `logs/maven-test.log`. Отчёт JaCoCo — `target/site/jacoco/index.html`. Сгенерированная документация API — `docs/api/index.html`. Её можно пересоздать без Maven:

```bash
javadoc -encoding UTF-8 -docencoding UTF-8 -charset UTF-8 \
  -d docs/api src/main/java/ru/petrov/tasktracker/TaskTracker.java
```

## Публичный контракт

Все классы ниже принадлежат `ru.petrov.tasktracker.TaskTracker`. Методы экземпляра предназначены для вызова из одного потока: потокобезопасность не гарантируется.

| Метод | Действие и результат |
|---|---|
| `new TaskTracker()` | Создаёт независимый пустой список. |
| `addTask(String text)` | Добавляет невыполненную задачу в конец; возвращает `ADDED`, пустое сообщение, `isSuccess() == true`, `shouldClearInput() == true`. При `null`, пустом или состоящем только из пробельных символов тексте возвращает `INVALID_TEXT`, `Текст задачи не может быть пустым!`, два признака `false`; список не меняется. |
| `completeTask(Integer index)` | По индексу с нуля отмечает задачу выполненной; возвращает `COMPLETED` и не требует очистки поля. Если `index == null`: `NO_SELECTION`, `Выберите задачу из списка!`; если уже выполнена: `ALREADY_COMPLETED`, `Эта задача уже выполнена`. При отказе список не меняется; количество и порядок не меняются при любом успешном выполнении. |
| `deleteTask(Integer index)` | Удаляет выбранную задачу и возвращает `DELETED`, не требуя очистки поля. Если `index == null`: `NO_SELECTION`, `Выберите задачу для удаления!`. Остальные задачи сохраняют текст, статус и порядок. |
| `getTasks()` | Возвращает неизменяемый снимок списка неизменяемых объектов `Task`. Последующие операции модели не меняют ранее полученные снимки. |
| `Task.getText()`, `Task.isCompleted()`, `Task.toDisplayString()` | Возвращают исходный текст, состояние и строку с префиксом `[ ] ` или `[✓] ` соответственно. |
| `Result.getOutcome()`, `Result.getMessage()`, `Result.isSuccess()`, `Result.shouldClearInput()` | Возвращают код, текст сообщения, признак успеха и признак необходимости очистить поле ввода. Успешные операции всегда имеют пустое сообщение. `isSuccess()` истинно только для `ADDED`, `COMPLETED`, `DELETED`; очистка поля требуется только при `ADDED`. |

**Решения для деталей, не заданных спецификацией:** `null` вместо текста считается пустым; `null` в параметре выбора означает отсутствие выбора. Числовой индекс за пределами `[0, размер)` — ошибка вызывающей стороны: выбрасывается `IndexOutOfBoundsException` с текстом `Индекс задачи вне диапазона: N`, состояние не меняется. Непустой текст сохраняется целиком, включая внешние пробелы; дубликаты допустимы, каждый является отдельной задачей. При проверке пустоты учитываются все кодовые точки, принимаемые Java `Character.isWhitespace` **или** `Character.isSpaceChar` (в том числе неразрывный пробел), но не каждый невидимый форматный символ. Это условия именно данной модели, а не утверждение о поведении EXE.

Для интерфейса `shouldClearInput()` — инструкция, а не само действие очистки. Сообщения возвращаются строкой; показ модальных окон, курсор и реальное поле ввода находятся вне модели и тестами не проверяются. Пример использования:

```java
TaskTracker tracker = new TaskTracker();
TaskTracker.Result added = tracker.addTask("Купить молоко");
if (added.shouldClearInput()) {
    // UI очищает своё поле ввода.
}
tracker.completeTask(0);
String line = tracker.getTasks().get(0).toDisplayString(); // [✓] Купить молоко
TaskTracker.Result warning = tracker.deleteTask(null);
// UI может показать warning.getMessage(): «Выберите задачу для удаления!»
```

При интеграции добавить `import ru.petrov.tasktracker.TaskTracker;`. Индексы всегда относятся к текущему снимку списка: при удалении позиции сдвигаются. Для аварийного неверного индекса вызывающий код обязан обработать исключение. Подробная процедура и результаты — в `REPORT.md`.
